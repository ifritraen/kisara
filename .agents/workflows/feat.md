---
description: Create a feature with highest craftsmanship, implement all dependencies, and iterate until perfect.
---
When the user executes `/feat [feature-request]`:

1. **Design & Planning Phase**:
   - Review relevant domain standards in `InfoBank/` (e.g., `web_standards.md` or `android_standards.md`).
   - Identify all files, schemas, assets, configurations, routing, and libraries required for the feature.
   - Design a premium UI/UX structure using modern design rules (glassmorphism, vibrant palettes, responsive grids, and micro-animations).

2. **Craftsman Implementation**:
   - Implement the core feature logic and user interfaces using production-grade, maintainable code.
   - Ensure maximum responsiveness, robust error bounds, loading states, and error handling.
   - Comment out, rather than delete, any legacy code replaced during implementation.

3. **Full Dependency Resolution**:
   - Proactively implement all helper classes, utility functions, databases, API integration, styling, and navigation links.
   - Ensure the new feature is fully integrated with no broken links, missing hooks, or unconfigured settings.

4. **Internal Quality Check** (no output to user):
   - Verify correctness, edge cases, code quality, UI/UX, and performance internally.
   - If obvious gaps exist, fix them before delivering. Do NOT output ratings unless the user asks.

5. **Deliver**:
   - Present the final implementation with a concise summary of key design decisions.
